# Game links

Every game has its own URL — open it directly, bookmark it, or share it. The home menu is optional.

**URL options** (all optional):
- `?d=easy|normal|hard` — preselect difficulty
- `?start=1` — skip the start card and begin immediately
- Table Rockstars only: `?tables=2,5,10` — preselect tables

Each game's start card has a **🔗 Share link** button that copies (or shares, on phones) a link with the current difficulty and `start=1`.
Installed PWAs also get home-screen **shortcuts** (long-press the icon) for Table Rockstars, Snake, 2048 and Sudoku 9×9.
